## (a) 題目解剖

> Analytical solutions for steady seepage into an underwater circular tunnel

- **開頭元素＝方法（解的類型）**：以 "Analytical solutions" 領頭，與 Fahimifar & Zareifard (2009) 的 "A theoretical solution" 同屬 TUST 的「解法宣告型」題目家族。`title_leads_with = method`。
- **有方法詞**：`Analytical solutions`、`steady seepage` 皆為方法／物理過程詞；無案例名、無地名、無數字。
- **構式**：`[解型（複數）] for [物理過程] into [幾何限定的對象]`
  - 三段式：解型（Analytical solutions）→ 過程（steady seepage）→ 對象（an underwater circular tunnel）。
  - **複數 "solutions" 是刻意的**：本文一次給兩組解（§3.1 定水頭邊界、§3.2 定水壓邊界），複數形正是差異化訊號——同族前作（Kolymbas & Wagner 2007、El Tani 2003）都只給一組。

- **"underwater" 是關鍵字資產**：全文四個 Keywords（Underwater tunnel / Steady seepage / Conformal mapping / Analytical solution）中三個直接複製自題目，題目＝關鍵字集合，SEO 式寫法。

  1. **§3.2 的解不滿足 Laplace 方程（僅滿足兩條邊界條件）**。Eq. (22)/(24) 的形式為 `p = γ(h_w−y) + f(x,y)·A(x,y)/(−2·arccosh(h/r))`，其中 `A = ln[(x²+(y+c)²)/(x²+(y−c)²)]` 為調和函數，但 `f` 含 `γ·r·sin(arctan((h+y)/x))` 並非常數。由 `∇²(fA) = A∇²f + 2∇f·∇A + f∇²A`，即使 f 為調和，交叉項 `2∇f·∇A ≠ 0`，故 p 在內域**非調和**。作者在 (18)–(21) 只用「引入待定函數 X、Y 由邊界條件決定」帶過，未檢驗控制方程。→ **§4.1「近洞吻合、遠場發散」的更可能原因是此非調和性，而非 FLAC3d 的邊界約束**（我方若引用需以此為據，並將 §3.2 定位為「邊界精確、內域近似」）。

## (h) 對我方的啟示（營運山岳鐵路隧道襯砌裂縫 × 地下水位循環 × 跨尺度 FDM-DEM）

### 啟示 1：h_w 這個參數＝我方「地下水位循環」的天然解析通道，且可導出一個「屏蔽函數」
本文最大的差異化資產是把**地表以上水深 h_w 顯式保留在解中**（§4.2 明說 Harr 解沒有這個變數）。對我方最有價值的推論——由 Eq. (24) 對 h_w 微分（**此為本筆記之推導，原文未提供**）：

```
∂p/∂h_w = γ · S(x,y),   S(x,y) = 1 + A(x,y) / (2·arccosh(h/r))
A(x,y) = ln[ (x² + (y+c)²) / (x² + (y−c)²) ],   c = √(h²−r²)
```
S 為無因次「水位屏蔽函數」：**洞壁上 A = −2·arccosh(h/r) → S = 0；地表上 A = 0 → S = 1**。
→ **在理想全排水（p_w=0）襯砌下，穩態時水位循環 Δh_w 對洞壁孔壓的影響恰為零**，影響隨遠離洞壁單調回升。
（實算，h=20 m、r=5 m：y=−1 m 時 S=0.950；−5 m 時 0.744；−10 m 時 0.446；−14 m 時 0.114；洞頂 −15 m 時 0.000。）
→ **這是我方 Ch.5 的論證支點**：既然完美排水在穩態下完全屏蔽水位循環，我方模型中襯砌裂縫感受到的水位循環孔壓響應**必定**來自下列三者之一——(i) 暫態儲水／非穩態（本文假設 (2) 排除）、(ii) 排水系統淤塞使 p_w > 0（本文的 p_w 可直接當淤塞程度指標）、(iii) 裂縫優選路徑造成的局部非均質（本文假設 (1) 排除）。**本文的三條假設，恰好一一對應我方的三個貢獻維度。**

### Q2. 孔隙水壓／水頭分佈的閉合式與關鍵無因次群

**共用記號**（本筆記統一整理；原文散在 Eqs. (6)(10)）：
```
c = √(h² − r²)                                （鏡像奇點的精確位置）
ρ = √(x² + (y+c)²),  ω = √(x² + (y−c)²)        （Eq. 6）
A(x,y) = ln(ρ²/ω²) = ln[(x²+(y+c)²)/(x²+(y−c)²)]
2·ln[h/r − √((h/r)²−1)] = −2·arccosh(h/r) ≡ −2L      （Eq. 10 的等價形；原文用前者）
```
座標：地表 y = 0，y 向上為正，洞心位於 (0, −h)。**洞周上 A ≡ −2L（常數）**——這是全部解的骨架。

**(A) 定水頭邊界（§3.1，Eq. 12）**：
```
H(x,y) = H_e + (H_w − H_e) · A(x,y) / (−2L)
```
對應孔壓（Eq. 13，H = y + p/γ）：
```
p(x,y) = γ(h_w − y) + (γH_w − γh_w) · A(x,y) / (−2L)
```
原文自述此式「與 Kolymbas & Wagner (2007) 的嚴謹解一致」——**這一支是嚴格解**。

**(B) 定水壓邊界（§3.2，Eq. 22；p_w = 0 時為 Eq. 24）**：
```
p(x,y) = γ(h_w − y) + [ p_w + γ·r·sin(arctan((h+y)/x)) − γh_w − γh ] · A(x,y) / (−2L)
```
```
（p_w = 0，Eq. 24）
p(x,y) = γ(h_w − y) + γ[ r·sin(arctan((h+y)/x)) − h_w − h ] · A(x,y) / (−2L)
```
對應水頭（Eq. 23）：
```
H(x,y) = h_w + [ p_w/γ + r·sin(arctan((h+y)/x)) − h_w − h ] · A(x,y) / (−2L)
```
> 洞周上 `sin(arctan((h+y)/x)) = (h+y)/r`，故中括號 = p_w/γ + y − h_w；代入 A = −2L 得 `p = p_w` ✓。**本筆記已數值驗證：h=20、r=5、h_w=30、p_w=0，在洞頂/洞底/腰部/45° 四點算得 p = 0.0000 kPa（誤差 < 1e−9），全周精確滿足。**

**(C) 湧水量閉合式：⚠ 原文未提供**
Q_w 僅出現在 Eq. (4) 作為映射尺度常數，之後被 Eq. (7) 的線性內插吸收，全文無 Q_w 的顯式解。標題／結論宣稱的 "steady water inflow" 其公式外包給 Huangfu et al. (2009) *Engineering Sciences* 11(7), 66–70。
**我方若需湧水量對照，應改引同族（本文 Eq. 12 自述與之一致）的標準式**——標明來源為 Kolymbas & Wagner (2007) / Goodman 型，**非本文**：
```
Q = 2πk·ΔH / arccosh(h/r) = 2πk·ΔH / ln[ h/r + √((h/r)²−1) ]     （深埋時 ≈ 2πk·ΔH / ln(2h/r)）
```
（實算，k=1e-5 m/s、r=5 m：h=20 m → 6.09e−4；h=50 m → 1.05e−3；h=100 m → 1.70e−3 m³/s/m。h=100 m 時 arccosh(h/r)=3.6883 vs ln(2h/r)=3.6889，**深埋近似誤差 < 0.02%**。）

**關鍵無因次群（四個）**：
| 群 | 定義 | 在解中的角色 | 原文給的數值 |
|---|---|---|---|
| **h/r（或 r/h）** | 埋深／半徑比 | **主控群**。以 `L = arccosh(h/r)` 出現在所有分母；並經 `c = r√((h/r)²−1)` 決定鏡像奇點位置 | r/h = 0.5、0.25、0.1（後者誤差 2.4%） |

### Q4. 該文如何處理「襯砌排水與否」此一分歧

**答：本文完全不建模襯砌本體，而把整個分歧壓縮成「洞周邊界條件的兩選一」。**

1. **不存在襯砌實體**：全文（含 24 條式子與 7 張圖）沒有任何襯砌厚度、襯砌滲透係數 k_l、地層/襯砌滲透比 k_l/k、灌漿圈或排水管的參數。與後續文獻常見的「複合介質 k_l/k 比值法」路線**完全不同**——本文是純邊界條件法。
2. **兩支解＝兩種襯砌狀態的理想化**：
   - **§3.1 定水頭 H_w（Eq. 12/13）**：洞周為**等勢面**。物理上對應「洞周孔壓隨高程線性變化」的情形，數學上最乾淨（此支為嚴格解，與 Kolymbas & Wagner 2007 一致），但**對自由排水的襯砌並不正確**——若取 H_w 為洞心高程，則洞頂 p = −γr、洞底 p = +γr，洞頂出現負壓，物理上不合理。
   - **§3.2 定水壓 p_w（Eq. 22/23；p_w=0 即 Eq. 24）**：洞周為**等壓面**，水頭沿洞周隨高程變化。**這才是排水型襯砌（大氣壓、自由出流）的正確理想化**。前言第 2 段的稀缺性宣告正是針對此支：定水壓邊界的解「文獻中幾乎找不到」。
3. **p_w 就是「排水程度」的連續參數**：Eq. (22) 保留一般 p_w，因此
   - `p_w = 0` → **全排水襯砌**（我方情形），得 Eq. (24)；
   - `0 < p_w < γ(h_w+h)` → **部分排水／排水系統淤塞**；
   - `p_w = γ(h_w+h)` → 洞周孔壓＝原始靜水壓 → **全封堵（不排水）襯砌，滲流為零**。
   **本文沒有明說這三段詮釋，但 Eq. (22) 的結構直接支持——這是我方可以引用並延伸的槓桿點：把 p_w 當作排水系統劣化指標。**
4. **本文的算例全部只跑 p_w = 0**：§4.1（h_w=30 m）與 §4.2（h_w=0 m）兩個算例都設 p_w = 0，**沒有任何 p_w > 0 的算例、沒有 p_w 的參數掃描、也沒有 §3.1 與 §3.2 的互相比較**。因此本文雖給了處理分歧的框架，卻沒有量化分歧的後果。
5. **對我方（排水型、pp = 0）的直接結論**：
   - 引用時應寫「採 Huangfu et al. (2010) §3.2 的定水壓公式（Eq. 24），對應自由排水襯砌 p = 0 之邊界」，**明確排除 §3.1**。
   - 我方可主張的缺口延伸（三條，逐條對應本文的一項未做）：**(i) p_w > 0 的部分排水情形未算 → 我方以排水淤塞演化補之；(ii) 兩種邊界的差異未量化（差值 ~2rγ ≈ 98 kPa @ r=5 m）→ 我方可補做；(iii) 襯砌未作為獨立介質、裂縫未參與導水 → 我方 FDM-DEM 的核心貢獻。**
